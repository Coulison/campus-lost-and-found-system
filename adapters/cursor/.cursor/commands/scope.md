# Scope

Cut the most recent PRD down to what your team can build in a fixed time budget, single-agent.

Usage: give me `<hours> <team_size> [skill_level]` as arguments.

Find the latest `output/<slug>/prd.md`. Load `.cursor/skills/mvp-scoping/SKILL.md` and follow its method exactly to write `mvp-scope.md` beside the PRD, using the given hours and team_size (skill_level defaults to "mixed" if omitted). If hours or team_size is missing, ask for it before proceeding. Read the PRD — do not re-derive requirements from the raw idea. Report the `mvp-scope.md` path plus its Build Now / Parked summary.
